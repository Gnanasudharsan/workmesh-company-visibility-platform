# Architecture decision log

Short records of decisions that shape the system. Each lists the alternative considered.

### ADR-1 Modular monolith
One NestJS service (feature folders, one DI container) plus an optional standalone worker. *Alternative*: microservices — rejected: no scaling need at 20–150 people, much harder local development and cross-service authorization.

### ADR-2 Pure, shared policy engine in `@workmesh/core`
Authorization logic is a framework-free package used by API (enforcement) and web (labels, transitions). *Alternative*: OpenFGA. Evaluated: valuable for very large relationship graphs, but it adds a service, a second source of truth to sync, and harder local setup; WorkMesh's relationship sets (≤ a few hundred members) are cheap to load per request and easy to cache by version. Revisit if tenants grow by orders of magnitude.

### ADR-3 RLS as defense in depth
Application authorization **and** PostgreSQL row-level security with a `NOBYPASSRLS` role and transaction-local tenant setting. *Alternative*: schema- or database-per-tenant — stronger isolation but heavy operational cost for small tenants. *Alternative*: app checks only — one missed `where` clause away from a leak.

### ADR-4 One transaction per organization-scoped request
Simplifies atomicity, outbox consistency and RLS context. Cost: a pooled connection is held for the request duration — acceptable for this workload; long-running reports would move to a read replica.

### ADR-5 Summary vs details as first-class access levels
Enables "deliberate public summaries" (name, team, status, health) without leaking content; `RESTRICTED` disables summaries entirely so existence never leaks.

### ADR-6 Versioned AuthContext cache
Cache keyed by `(org, member)` and stamped with `organizations.authzVersion`, bumped in the same transaction as any access-affecting change. *Alternative*: TTL-only cache — revocation would lag. *Alternative*: no cache — ~11 queries per request.

### ADR-7 Transactional outbox + BullMQ
Durable delivery without two-phase commit; jobId = outbox id for dedupe; a poller recovers lost enqueues. *Alternative*: emit directly after commit — events lost on crash.

### ADR-8 Realtime carries IDs, not data
Sockets receive event types and IDs in per-member rooms; clients refetch via REST. Keeps a single authorization path and makes reconnection trivial.

### ADR-9 Deterministic briefs, no LLM
Briefs are computed from structured change events; every claim links to a record. Explainable, free to run, testable, and nothing is invented.

### ADR-10 Honest progress
Computed progress (milestone-weighted, critical × 2) separate from owner-reported estimates; rule-based health with reasons; no deadline predictions — only slack evidence.

### ADR-11 Opaque server sessions, not JWT
Instant revocation (password reset, deactivation), small cookies, no token in JS. CSRF handled with SameSite + Origin + double submit.

### ADR-12 Prisma 6, Nest 11, TypeScript 5.9
Chosen over the newest majors (Prisma 7, Nest 12, TypeScript 7) available at build time for ecosystem stability (ts-jest, decorators metadata, migration tooling). Upgrading is planned work, not a blocker.

### ADR-13 shadcn-style components on Radix
Components are owned in-repo (copied-in pattern) rather than generated by the shadcn CLI, giving full control over the design tokens.

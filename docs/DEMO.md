# Demo guide

**Northstar Labs** and **Meridian Systems** are fictional companies; all people, projects and updates are synthetic.

```bash
make demo    # setup + seed + start; open http://localhost:3002/login
```

The login page (DEMO_MODE only) has one-click personas. The demo password for every seeded user is in `.demo-credentials.json` (git-ignored, regenerated by `make seed`).

## Walkthroughs (these are the automated Playwright journeys)

- **A — Onboarding**: Sam → Administration → Invitations → invite to Payments with Daniel as manager → open `/dev/mailbox` → follow the link → accept → onboarding shows manager, team, goals; the Work map has no Project Atlas.
- **B — Progress update**: Maya → *Share an update* → Payment Gateway Integration, stage Testing, "I'm blocked…" → publish to *My management chain* → Daniel sees it in Team Pulse and the blocker queue → Rachel (Sales) gets "Not available" for the update URL.
- **C — Manager oversight**: Daniel → blocker → assign Hannah → Team Pulse → *+ Action* for Maya → Maya sees it in My Work.
- **D — Discovery**: Maya → Directory → Teams → search "pricing" → Sales team responsibilities and contact; Enterprise Pricing (Sales-only) isn't listed; Design System v2 is open to all; Project Atlas URL → "Not available".
- **E — Dependencies**: Priya → Checkout Launch → Dependencies → add "depends on Observability Overhaul" → mark Blocked → Daniel's dependency explorer shows Checkout as a confirmed problem and PLG as potentially impacted → resolve → impact clears.
- **F — Meeting**: Daniel → Payments weekly sync → Brief (new blockers, help requests, deadlines, pending actions) → record a decision → assign an action item to Maya → Maya sees it in the meeting's action items and summary.
- **G — Isolation**: Noah opens a Northstar project URL → "Not available"; ⌘K "Checkout" → no results; graph/search/directory APIs return nothing from Northstar; a socket subscription to Northstar is rejected.

Also worth trying: Company Map (expand Engineering → Payments, *Reporting subtree* on Daniel), Roadmaps (timeline/board/goals), Leadership as Elena, the permission inspector as Sam (inspect Sam on *Customer Health Score* — admin, yet no details).

## Midnight Edition tour (5 minutes)

1. **Login** — the navy *Living WorkMesh* panel is decorative; pick **Employee · Maya Chen**.
2. **Home** — the navy hero shows Maya's real counts; *How your work connects* traces her assignments up to
   company goals (hover a node to light its path). The *Getting started* guide ticks off as you go.
3. **Company Map** — click Engineering → Payments → Maya: the camera glides to her and the inspector opens.
   Switch to **Work** to follow projects to goals.
4. Sign in as **Manager · Daniel Okafor** → **Team Pulse**: the status donut, report cards (try *List*),
   blocker radar and action queue.
5. **Dependencies** → **Impact**: only confirmed problems and what they can reach stay lit.
6. Sign in as **Executive · Elena Vasquez** → **Leadership**: goal rings, portfolio donut, department health
   and the strategic milestone timeline.
7. Collapse the sidebar (chevron on its edge), press **⌘K**, and try the app at phone width.
